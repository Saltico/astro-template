# Hello World

Welcome to your new **Astro static site**! This is your first blog post, editable through Keystatic at `/keystatic`.

## What's included

This template comes with:

- **SEO**: Auto-generated canonical URLs, JSON-LD schemas
- **Analytics**: Google Tag Manager + GA4 (conditional on env vars)
- **Consent Mode v2**: Cookie banner with proper consent handling
- **Tailwind v4**: CSS-first design tokens, no config file needed
- **Keystatic CMS**: Edit content locally in dev mode
- **WordPress headless**: Optional migration path (documented in README)

## Next steps

1. Edit this post at `/keystatic`
2. Add your brand colors in `src/styles/tokens.css`
3. Update `src/data/site.ts` with your site info
4. Set your analytics IDs in `.env`
5. Deploy to your favorite static host

Happy building!

# About This Template

This is a reusable, SEO-optimized static website template built with **Astro**, **Tailwind CSS v4**, and **Keystatic CMS**.

## Features

- **Static-first**: Blazing fast performance with Astro's static site generation
- **SEO**: Auto-generated canonical URLs, Open Graph, JSON-LD structured data
- **Analytics**: Google Tag Manager + GA4 with Consent Mode v2
- **CMS**: Keystatic for local content editing
- **WordPress**: Optional headless integration (see README)

## How to use

Edit this page at `/keystatic` (dev mode) or directly in `src/content/pages/about.mdx`.
